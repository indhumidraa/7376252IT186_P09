1. PROJECT DESCRIPTION
----------------------
The Contact Book Management System is a Python 3 terminal-based
application used to store and manage contact information.

It allows users to add, view, search, edit, and delete contacts.
Contact information is stored in a plain-text file named contacts.txt,
so the data remains available after the program is closed.

2. FEATURES
-----------
- Add new contacts
- View all saved contacts
- Search contacts by name or phone number
- Edit a contact's name, phone number, email, or all details
- Delete contacts with confirmation
- Save contact information in a text file
- Validate user input and prevent duplicate contact details

3. TECHNOLOGIES USED
--------------------
- Python 3
- File handling
- Functions
- Lists and dictionaries
- Loops and conditional statements
- Plain-text file storage

4. PROJECT FILES
----------------
main.py       - Contains the Python program.
contacts.txt  - Stores contact information.
README.txt    - Describes the project and instructions.
sample_run.txt - Contains an example program execution.

5. HOW TO RUN
-------------
1. Install Python 3 on your computer.
2. Keep main.py and contacts.txt in the same folder.
3. Open PowerShell or Command Prompt in the project folder.
4. Run the command:

   py main.py

5. Select an option from the menu.
6. Follow the instructions displayed on the screen.
7. Select Exit to close the application.

6. DATA STORAGE
---------------
Contacts are stored in contacts.txt.

Each contact is stored on a separate line in this format:

Name|Phone|Email

Example:
Arun Kumar|9876543210|arun@gmail.com

7. CONCLUSION
-------------
This project demonstrates basic Python programming, functions,
data structures, input validation, and file handling. It provides
a simple way to manage contact information through a terminal menu.
